# Personal Portfolio

This repo contains the deployment content for my GitHub Pages. The website is built using HTML, CSS, and vanilla JS, with its UI/UX was inspired by [Asadi's Personal Website](https://github.com/AsadiAhmad/Personal-Website) and [Muhammad Sufyan's Personal Website](https://muhammadsufyan.my.id/), and I would like to thank them for the inspiration. Although both of them use existing CSS frameworks, I use plain CSS because I am not quite into web development, and this is my first deployed website besides Blogspot. Still, I managed to reproduce the same vibe (I think) from both of them.

The website contains my professional contact information and a brief introduction about me. More importantly, it serves as a place to showcase my projects and link to all of them in one place. In the future, I also plan to write articles about things I want to share, most likely mathematics or perhaps some interesting data insights around us.
