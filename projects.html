Math Gacha

Python

Latex

HTML

CSS

JavaScript

I've built this project using Python, LaTeX, HTML, CSS, and JavaScript to make practicing competition problems more random and interactive. It converts your LaTeX problem files into CSV or JSON, which can then be loaded into the web app as a problem database. The app turns the database into a spinning gacha machine, so you can randomly pick problems instead of solving them in the original contest order. You can use it for individual practice or challenge a friend to see who can solve the selected problem first. The project is open to use, and you can clone it if you're familiar with GitHub.
